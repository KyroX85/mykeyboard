# Rejected Directions

These directions are rejected, paused, or deprioritized unless the founder explicitly reopens them.

## Rejected As Primary Differentiators

- Better prediction as the main reason to switch from Gboard.
- Better swipe as the main reason to switch from Gboard.
- Themes/settings as the main reason to switch from Gboard.
- Architecture cleanup as product progress.
- Generic multi-agent sophistication without user leverage.

## Rejected Execution Patterns

- Auto-send messages.
- Silent app control.
- Autonomous protected keyboard rewrites.
- Mutation from vague chat prompts.
- Creating reports instead of answering simple product questions.
- Treating conversation as execution.

## Rejected Product Directions For Now

- AI companion/emotional simulation as the immediate active feature.
- Fake personality or chatbot-first behavior.
- Cloud telemetry.
- Raw typing collection.
- Raw screenshot retention.
- Hidden behavioral surveillance.

## Rejected Activation Ideas

- Long-press spacebar.
- Double-tap spacebar.
- Two-finger gestures.
- Typing shortcuts that interfere with typing intent.

## Rejected Agent Behaviors

- Menu loops for normal conversation.
- "Task accepted" for product discussion.
- "LOW INFORMATION" for valid product questions.
- Generic roadmap templates when asked for founder-state understanding.
- Inventing roadmap items not present in founder memory.
