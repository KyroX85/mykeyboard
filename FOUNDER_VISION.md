# Founder Vision

## Active Vision

Aritenis is an Android keyboard that becomes a trusted local-first intelligence layer inside the user's typing flow.

The current evolved direction is:

Users should be able to understand confusing content before they type.

The keyboard should help with moments like:

- screenshots
- messages
- bills
- notices
- forms
- errors
- posts
- documents

The user should not need to leave the current app, open a separate chatbot, or expose private context unnecessarily.

## Ultimate Aim

The long-term aim is not to build a generic keyboard or a generic chatbot.

The aim is to build a keyboard-based intelligence layer that feels trusted, private, culturally aware, and useful at the exact moment the user needs help.

Historical founder vision also included an emotional AI keyboard / digital best friend direction for Indian users. That remains important founder DNA, but it is not the active implementation priority unless the founder explicitly reactivates it.

## Product Doctrine

- Trust before intelligence.
- Privacy before convenience.
- Keyboard stability before Phase 2 features.
- Understanding before typing.
- Confirmation before action.
- No automatic sending.
- No raw personal typing collection.
- No hidden cloud telemetry.

## Current North Star

Build the first keyboard that helps users understand before they type.
